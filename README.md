# Книжница

Локальное приложение для Windows, чтобы писать книги: главы, персонажи, план, поиск, корзина, резервные копии и экспорт в Word.

Всё хранится на вашем компьютере — никаких аккаунтов, облака и интернета.

## Установка

1. Откройте раздел [**Releases**](../../releases) и скачайте `Knizhnitsa-Setup.exe`.
2. Запустите его. Установка идёт **для текущего пользователя**, пароль администратора не нужен.
3. После установки «Книжница» появится в меню Пуск и на рабочем столе.

> **Про предупреждение Windows.** Программа пока не подписана сертификатом, поэтому
> при запуске установщика Windows может показать синее окно «Windows защитила ваш
> компьютер». Это нормально для новых небольших программ: нажмите
> **«Подробнее» → «Выполнить в любом случае»**. Исходный код полностью открыт —
> можете проверить его в этом репозитории.

## Что уже есть

- несколько книг в одной библиотеке;
- главы с автосохранением и историей версий;
- карточки персонажей;
- поиск по книгам, главам, персонажам и плану;
- корзина вместо удаления навсегда;
- план книги по главам;
- экспорт в `.docx` и `.txt`;
- локальные резервные копии.

## Где хранятся данные

Книги хранятся на компьютере пользователя:

```text
%APPDATA%\Книжница\library.json
```

Автоматические копии хранятся рядом:

```text
%APPDATA%\Книжница\Резервные копии
```

## Сборка

```powershell
cd app
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean .\Книжница.spec
```

Готовая программа (onedir — запускается мгновенно, без распаковки) появится в:

```text
app\dist\Книжница\Книжница.exe
```

## Установщик

Нужен [Inno Setup 6](https://jrsoftware.org/isdl.php). Сборка установщика:

```powershell
cd app
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

Готовый установщик появится в:

```text
app\dist\installer\Книжница-Setup.exe
```

Он ставит программу для текущего пользователя (без пароля администратора),
создаёт ярлыки в меню Пуск и на рабочем столе, добавляет запись в
«Установка и удаление программ» и закрывает запущенную копию перед обновлением.
Книги при удалении не трогаются — они лежат в `%APPDATA%\Книжница`.
