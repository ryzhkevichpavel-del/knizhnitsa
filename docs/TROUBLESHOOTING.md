# Решение частых проблем

## Windows предупреждает о неизвестном издателе

Проверьте заметки к выпуску. Если установщик помечен как неподписанный,
SmartScreen может показать предупреждение. Это не скрывается: неподписанный
выпуск так и называется на странице скачивания.

Скачивайте `Avtoreya-Setup.exe` только со страницы Releases этого репозитория.
Если браузер или антивирус сообщает не обычное предупреждение SmartScreen, а
обнаружение вредоносного файла, не запускайте его и создайте issue без
прикрепления личных рукописей.

## Сборщик не находит Inno Setup

Установите Inno Setup 6. `build_release.ps1` ищет `ISCC.exe` в `PATH`, в папке
локальных программ пользователя и в стандартных папках Program Files.

## Сборщик не находит Python или Node.js

Для выпуска нужны Python 3.11 и Node.js. Проверьте их в PowerShell:

```powershell
python --version
node --version
```

Затем установите закреплённые зависимости:

```powershell
cd app
python -m pip install -r requirements.txt
```

## Подписанная сборка не запускается

Режим `Signed` требует сертификат подписи кода в хранилище сертификатов Windows
и его точный отпечаток:

```powershell
.\build_release.ps1 -Mode Signed -CertificateThumbprint "ОТПЕЧАТОК_СЕРТИФИКАТА"
```

Локально действительная подпись не равна публичному доверию Windows. Для
SmartScreen важны подходящий доверенный сертификат и репутация издателя.

## Приложение не запускается

Журнал запуска находится здесь:

```text
%APPDATA%\Авторея\startup.log
```

Откройте эту строку через `Win + R`. При создании issue приложите только журнал;
не прикладывайте `library.json`, резервные копии или реальные рукописи.

## Где находятся книги и резервные копии

```text
%APPDATA%\Авторея\library.json
%APPDATA%\Авторея\Резервные копии
```

Переустановка приложения не должна удалять эти данные. Перед ручными действиями
с `library.json` полностью закройте Авторею и скопируйте всю папку
`%APPDATA%\Авторея` в безопасное место.
